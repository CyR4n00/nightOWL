## 2024-07-17 - Password Visibility Toggle Constraints
**Learning:** The AuthView component uses absolute positioning for icons inside input wrappers. When adding interactive elements like a password toggle to the right side of the input, the text padding must be explicitly adjusted (e.g., from `pr-4` to `pr-12`) to prevent the user's typed password from physically overlapping the interactive toggle icon. Also, Vite's preview server will fail to start if the frontend is missing a valid build directory (`dist/`) or missing `.env` config, meaning a build step and copying `.env.example` to `.env` is always required prior to Playwright verification. To bypass `GateView` in automation scripts, `page.get_by_role('button', name='デバッグ用強制起動').click()` can be used.
**Action:** When adding right-aligned floating interactive elements to any input field in this codebase, immediately pair the change with a corresponding padding-right (`pr-*`) adjustment on the input element itself to preserve readability. Ensure Playwright scripts account for environment initialization.
